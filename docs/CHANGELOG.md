# Changelog

이 문서는 LooPyck(루픽)의 주요 변경 사항을 기록합니다.
형식은 [Keep a Changelog](https://keepachangelog.com/ko/1.0.0/)를 따르며, 버전은 [유의적 버전](https://semver.org/lang/ko/)을 사용합니다.

## [1.1.0] - 2026-06-12

가격 비교 진입 흐름(브랜드·카테고리 랜딩 → 검색 결과 → 비교 후보)을 하나의 일관된 다크 테마 경험으로 새단장한 릴리즈입니다.

### 디자인 개편

- **가격 비교 진입 화면 리디자인** — 브랜드(`/brand/무신사` 등)와 카테고리(`/category/스니커즈` 등) 페이지를 어두운 테마 기반의 비교 진입 화면으로 새로 디자인했습니다. 각 페이지에 현재 경로를 보여주는 칩, "비교 렌즈"(우선 보는 기준·따로 봐야 하는 경우·이 페이지의 역할) 카드, 곧바로 검색을 시작할 수 있는 입력창, 자주 쓰는 비교 루트 카드, 다른 브랜드·카테고리로 이어지는 칩 내비게이션을 한 흐름에 담았습니다.
- **검색 결과 비교 계층 정리** — 검색 결과 위쪽에 최저 결제가·비교 가능 상품 수·최대 가격 차이 요약을 먼저 보여주고, 여러 쇼핑몰에서 동시에 잡힌 "Compare Ready" 상품을 일반 결과보다 앞서 노출하도록 화면 위계를 다시 잡았습니다. 각 상품 카드에는 비교 쇼핑몰 수, 판매처 신뢰, PDP 확인 배지와 "+ 비교 후보 담기" 버튼을 정리해 한눈에 비교 판단이 가능하도록 했습니다.

### 버그 수정

- 검색 결과에서 "비교 후보 담기"를 눌러도 후보가 저장되지 않던 문제를 수정했습니다. 이제 로그인 없이 담은 비교 후보가 정상적으로 저장되고, 같은 기기에서 다시 열어 이어서 비교할 수 있습니다.

### 개선사항

- 다른 브랜드·카테고리로 이동하는 내비게이션 칩에 설명을 더해, 마우스를 올리지 않아도 모바일과 스크린리더 사용자가 각 항목의 의미를 알 수 있도록 했습니다.
- 비교 진입 화면의 일부 안내 문구 명암비를 높여 어두운 배경에서도 더 또렷하게 읽히도록 개선했습니다.

### 기술 개선

> 사용자 화면에는 직접 드러나지 않지만 안정성과 유지보수성을 높인 변경입니다.

- 검색 학습 운영 분석 로직을, 거의 같은 코드가 반복되던 재귀 모듈 28개에서 단일 제네릭 엔진과 레벨 설정 구조로 통합했습니다. 약 3,400줄을 줄였고, 변경 전후 출력이 동일함을 합성 데이터 검증으로 확인했습니다.
- 관리자 진단 대시보드의 체인 분석 UI를 설정 기반의 단일 렌더러로 통합했습니다(약 1,900줄 감소). 화면에 노출되는 라벨·문구·동작은 그대로 유지했습니다.
- 그 밖에 코드 리뷰에서 발견한 접근성·내부 설정 정리와 릴리즈 검증 안정화 등 자잘한 개선이 포함되었습니다.
